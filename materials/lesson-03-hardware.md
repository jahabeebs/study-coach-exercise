# Lesson 3: Computer Hardware

## The Central Processing Unit

The central processing unit (CPU) executes instructions. It repeatedly performs the
fetch-decode-execute cycle: fetch the next instruction from memory, decode what it
means, and execute it. CPU speed is measured in gigahertz (GHz), billions of cycles
per second. Modern CPUs contain multiple cores, each capable of executing instructions
independently, which allows a computer to make progress on several tasks at once.

## Memory and the Storage Hierarchy

Computers use a hierarchy of storage that trades speed against capacity and cost.
Registers inside the CPU are the fastest and smallest. Cache memory sits next to the
CPU cores and holds recently used data. Random access memory (RAM) is the computer's
working memory: it holds running programs and their data, and its contents are lost
when power is removed — RAM is volatile. Persistent storage — solid-state drives (SSD)
and hard disk drives (HDD) — retains data without power. SSDs use flash memory with no
moving parts and are much faster than HDDs, which store data on spinning magnetic
platters.

## The Motherboard and Buses

The motherboard is the main circuit board that connects every component. Buses are the
communication pathways that carry data between the CPU, memory, and devices. The
chipset manages traffic between components. Expansion slots allow additional cards,
such as a dedicated graphics card, to be added.

## Input and Output Devices

Input devices bring data into the computer: keyboards, mice, touchscreens, cameras,
and microphones. Output devices present results: monitors, speakers, and printers.
Ports such as USB provide standardized connections for peripherals. Device drivers are
software components that let the operating system communicate with specific hardware.

## The Graphics Processing Unit

The graphics processing unit (GPU) contains thousands of small cores designed to
perform many simple calculations simultaneously. GPUs were created to render images
and video, but their parallel design also makes them well suited to scientific
computing and training machine learning models.

## Moore's Law

In 1965, Gordon Moore observed that the number of transistors on a chip doubled
roughly every two years, an observation known as Moore's law. For decades this drove
exponential growth in computing power at falling cost. In recent years the pace has
slowed as transistors approach physical limits, pushing the industry toward multi-core
designs, specialized chips, and better software efficiency.
