# Glossary

## Terms A–F

- **Algorithm** — a precise, step-by-step procedure for solving a problem that always
  finishes and produces a correct result for valid input.
- **ASCII** — a 1963 standard assigning numbers to 128 characters; capital A is 65.
- **Binary** — the base-2 number system computers use; each digit is a bit, 0 or 1.
- **Bit** — the smallest unit of data; holds one of two values.
- **Byte** — eight bits; can represent 256 distinct values.
- **Cache** — small, fast memory near the CPU cores holding recently used data.
- **Compiler** — a translator that converts an entire high-level program into machine
  code before it runs.
- **CPU (central processing unit)** — the component that executes instructions via the
  fetch-decode-execute cycle.
- **DNS (Domain Name System)** — the distributed directory that translates domain
  names into IP addresses.

## Terms G–P

- **GPU (graphics processing unit)** — a chip with thousands of small cores for
  parallel computation; used for graphics and machine learning.
- **HTTP** — the request-response protocol browsers and web servers use.
- **HTTPS** — HTTP protected by encryption; provides confidentiality and integrity.
- **Integrated circuit** — many transistors fabricated on one silicon chip.
- **Interpreter** — a translator that executes a program line by line as it runs.
- **IP address** — the numeric address identifying a device on the internet.
- **Machine code** — binary instructions a CPU executes directly.
- **Packet** — a small chunk of data with source, destination, and sequence headers.
- **Pixel** — one cell in the grid that makes up a digital image.
- **Pseudocode** — structured, language-neutral text for describing algorithms.

## Terms Q–Z

- **RAM (random access memory)** — volatile working memory holding running programs;
  contents are lost when power is removed.
- **RGB** — the color model storing red, green, and blue intensity per pixel.
- **Router** — a device that forwards packets toward their destination address.
- **SSD (solid-state drive)** — persistent flash storage with no moving parts.
- **Transistor** — the electronic switch, invented at Bell Labs in 1947, that replaced
  the vacuum tube.
- **Turing machine** — Alan Turing's 1936 abstract machine defining what is computable.
- **Unicode** — the character standard covering more than 140,000 characters.
- **UTF-8** — the dominant web text encoding; ASCII-compatible, one to four bytes per
  character.
